# Applis Mirazuki pour Android TV

Trois applis indépendantes : installe seulement celles que tu veux. Si Mirazuki est installé, il propose aussi les deux autres dans **Réglages › Mises à jour et sauvegarde › Applis Mirazuki**, et affiche leurs rangées à l'accueil.

| Appli | Version stable | Version bêta |
|---|---|---|
| **Mirazuki** · launcher, bibliothèque unifiée | — | [4.0 bêta 46](https://github.com/miraiijo/mirazuki-releases/releases/download/channel/Mirazuki-beta.apk) |
| **Mirazuki Tube** · client YouTube sans publicité (non officiel) | — | [1.0 bêta 19](https://github.com/miraiijo/mirazuki-releases/releases/download/channel/MirazukiTube-beta.apk) |
| **Mirazuki IPTV** · lecteur IPTV (M3U, Xtream Codes, guide XMLTV), aucune chaîne fournie | — | [1.0 bêta 26](https://github.com/miraiijo/mirazuki-releases/releases/download/channel/MirazukiIPTV-beta.apk) |

Les liens sont fixes et donnent toujours la dernière version : pratique avec l'appli **Downloader** sur la box.

⚠️ **Bêtas** : elles arrivent plus tôt mais peuvent planter ou contenir des bugs. Les versions stables sont proposées par défaut.

## Installer

1. Sur la box : installe **Downloader** et autorise-le à installer des applis inconnues.
2. Ouvre un des liens ci-dessus dans Downloader, puis installe.
3. Les mises à jour se font ensuite dans l'appli : **Réglages › Mises à jour** (stable par défaut, bêtas sur demande).

Chaque APK est vérifié avant installation (taille, empreinte SHA-256, certificat de signature) ; l'empreinte de chaque version figure dans les notes de sa release. Aucune donnée personnelle n'est collectée par ces applis.
