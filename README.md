# Applis miryo. pour Android TV

Des applis indépendantes : installe seulement celles que tu veux. Si miryo est installé, il propose aussi miryo iptv dans **Réglages › Mises à jour et sauvegarde › Applis miryo**, et affiche ses rangées à l'accueil.

| Appli | Version stable | Version bêta |
|---|---|---|
| **miryo.** · launcher, bibliothèque unifiée | — | [4.0 bêta 62](https://github.com/miraiijo/miryo-releases/releases/download/channel/miryo-beta.apk) |
| **miryo iptv** · lecteur IPTV (M3U, Xtream Codes, guide XMLTV), aucune chaîne fournie | — | [1.0 bêta 36](https://github.com/miraiijo/miryo-releases/releases/download/channel/miryo-iptv-beta.apk) |

Les liens sont fixes et donnent toujours la dernière version : pratique avec l'appli **Downloader** sur la box.

## miryo tube

**miryo tube** (client YouTube non officiel, sans publicité) a sa propre page : [github.com/miraiijo/miryo-tube](https://github.com/miraiijo/miryo-tube). Ses versions sont publiées dans les Releases de ce dépôt, et il se met à jour tout seul une fois installé. Il n'est pas proposé dans miryo.

Il est basé sur [SmartTube](https://github.com/yuliskov/SmartTube) de yuliskov, sous licence MIT (Copyright (c) 2020-present yuliskov) : le fichier LICENSE et cet avis de copyright sont conservés dans son dépôt. Il n'a aucun lien avec SmartTube, YouTube ou Google.

⚠️ **Bêtas** : elles arrivent plus tôt mais peuvent planter ou contenir des bugs. Les versions stables sont proposées par défaut.

## Installer

1. Sur la box : installe **Downloader** et autorise-le à installer des applis inconnues.
2. Ouvre un des liens ci-dessus dans Downloader, puis installe.
3. Les mises à jour se font ensuite dans l'appli : **Réglages › Mises à jour** (stable par défaut, bêtas sur demande).

Chaque APK est vérifié avant installation (taille, empreinte SHA-256, certificat de signature) ; l'empreinte de chaque version figure dans les notes de sa release. Aucune donnée personnelle n'est collectée par ces applis.
